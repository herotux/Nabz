## نصب روی Manjaro و Arch Linux

برای نصب نسخهٔ بومی روی سیستم‌های ۶۴ بیتی مبتنی بر Arch (از جمله Manjaro)، ترمینال را با کاربر عادی باز کن و اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/herotux/Nabz/main/install.sh | bash
```

نصب‌کننده ابزارهای ساخت لازم را از مخازن رسمی با pacman دریافت می‌کند، آخرین سورس شاخه `main` را می‌گیرد و با `makepkg` بستهٔ بومی Arch را می‌سازد و نصب می‌کند. هیچ فایل AppImage، DEB یا Flatpak نصب نمی‌شود.

**نکات مهم**
- برای نصب، اتصال اینترنت و دسترسی sudo لازم است.
- اولین ساخت ممکن است به‌دلیل دریافت وابستگی‌های Rust چند دقیقه طول بکشد.
- اجرای برنامه پس از نصب: `nabz`
- دیتابیس در `~/.local/share/nabz/nabz.sqlite3` ذخیره می‌شود.
- نصب یا ارتقای بسته دیتابیس را پاک نمی‌کند.
- حذف برنامه با `sudo pacman -R nabz` انجام می‌شود و اطلاعات کاربر را حذف نمی‌کند.
- برای حذف کامل اطلاعات، پوشهٔ `~/.local/share/nabz` را فقط پس از تهیهٔ نسخهٔ پشتیبان، جداگانه حذف کن.
- این نصب‌کننده فعلاً فقط برای x86_64 است؛ پشتیبانی ARM و ویندوز در این اسکریپت وجود ندارد.

## ساخت دستی بسته

```bash
git clone https://github.com/herotux/Nabz.git
cd Nabz
makepkg -si
```
