# بازطراحی رابط نبض با React

این شاخهٔ کاری از `main` ساخته شده تا مسیر قدیمی دست‌نخورده بماند.

## تصمیم معماری
- پوسته دسکتاپ: Tauri 2
- رابط: React + TypeScript + Vite
- منطق مالی و پایگاه داده: فرمان‌های Rust و SQLite فعلی؛ رابط جدید فقط از قراردادهای موجود فراخوانی می‌کند.
- ظاهر: طراحی اختصاصی، راست‌چین، فونت Vazirmatn محلی، رنگ‌های خنثی و سبز برای عملیات اصلی.
- موبایل: چیدمان واکنش‌گرا با منوی کناری جمع‌شونده.

## وضعیت این مرحله
- [x] افزودن React و React DOM و پیکربندی TSX
- [x] جایگزینی ورودی HTML با React
- [x] پوسته ناوبری و داشبورد جدید
- [x] اتصال فهرست‌ها و عملیات اصلی ثبت، حذف، چاپ و پشتیبان‌گیری به فرمان‌های Tauri موجود
- [ ] اجرای TypeScript/Vite و تست Rust در CI
- [ ] بازبینی همهٔ گردش‌های حسابداری و چاپ روی Manjaro
- [ ] تکمیل جزئیات، ویرایش امن اسناد، فیلترهای پیشرفته و صفحه‌بندی
- [ ] استخراج منطق مالی به `nabz-core` مشترک؛ هنوز کد حسابداری اصلی در crate مستقل منتقل نشده است.
- [ ] ایجاد لایهٔ API برای اجرای واقعی نسخه وب؛ فرمان‌های فعلی `invoke` فقط در پوسته Tauri به SQLite محلی وصل می‌شوند. نسخه وب عمومی بدون backend مجزا آماده نیست.

## حفاظت از داده
این شاخه از مسیر دیتابیس Tauri فعلی استفاده می‌کند و نباید فایل دیتابیس را جابه‌جا یا بازنویسی کند. پیش از انتشار باید مسیر دادهٔ نسخه نصب‌شده و مهاجرت‌ها با آزمون عملی تأیید شود.
