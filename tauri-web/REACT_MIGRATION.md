# تثبیت مسیر React/Tauri

آخرین بازبینی: 2026-11-17

## تصمیم نهایی

مسیر فعال محصول React + TypeScript + Vite در پوستهٔ Tauri 2 است. Slint از برنامهٔ نهایی کنار گذاشته شده و egui فقط برای نگهداری و بررسی دیتای قدیمی باقی می‌ماند.

- [x] رابط React/TypeScript و ناوبری واکنش‌گرا
- [x] فرم‌های پایهٔ طرف‌حساب، کالا، فاکتور و پرداخت
- [x] تاریخ شمسی، ارقام فارسی و گزارش بازه‌ای
- [x] تولید Code 128 و ورودی اسکنر USB/HID
- [x] پشتیبان‌گیری و بازیابی JSON
- [x] بستهٔ بومی Arch/Manjaro در CI

- [x] مستندسازی مسیر فعال و قواعد معماری

## دیتابیس و حفظ داده

شناسهٔ Tauri برابر `com.herotux.nabz.webprototype` باقی مانده و مسیر پیش‌فرض در Linux برابر `~/.local/share/com.herotux.nabz.webprototype/nabz.sqlite3` است.

دیتابیس egui قدیمی در `~/.local/share/nabz/nabz.sqlite3` قرار دارد. این دو دیتابیس جدا هستند؛ دیتابیس egui هنوز import نشده و باید با preview، backup و تأیید نگاشت مانده‌ها و پرداخت‌های قدیمی منتقل شود.

## سازگاری دادهٔ قدیمی

- برای موجودی افتتاحیهٔ کالاهای قدیمی، `average_cost` از `buy_price` فعلی مقداردهی می‌شود؛ این برآورد است و تاریخچهٔ واقعی خرید را بازسازی نمی‌کند.
