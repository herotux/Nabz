# تثبیت مسیر React/Tauri

## تصمیم نهایی

مسیر فعال محصول React + TypeScript + Vite در پوستهٔ Tauri 2 است. Slint از برنامهٔ نهایی کنار گذاشته شده و egui فقط به‌عنوان کد قدیمی برای بررسی و مهاجرت احتمالی داده نگه داشته می‌شود.

- [x] فرم‌های پایهٔ طرف‌حساب، کالا، فاکتور و پرداخت
- [x] تاریخ شمسی، ارقام فارسی و گزارش بازه‌ای
- [x] تولید Code 128 و ورودی اسکنر USB/HID

- [x] مستندسازی وضعیت و قواعد معماری

## دیتابیس و حفظ داده

شناسهٔ Tauri برابر `com.herotux.nabz.webprototype` است و در لینوکس مسیر پیش‌فرض دیتابیس معمولاً `~/.local/share/com.herotux.nabz.webprototype/nabz.sqlite3` است.

دیتابیس egui قدیمی در `~/.local/share/nabz/nabz.sqlite3` قرار دارد. این دو دیتابیس schema و مسیر جدا دارند. مهاجرت خودکار هنوز انجام نشده و هر دو باید بدون تغییر حفظ شوند.

## تفاوت هستهٔ PR شمارهٔ ۵

هستهٔ PR شمارهٔ ۵ schema نسخهٔ ۶، migration، میانگین موزون، بهای تمام‌شدهٔ تاریخی و عملیات برگشت/ابطال را فراهم می‌کند. کد Tauri فعلی هنوز SQL و فرمان‌های حسابداری خودش را در `src-tauri/src/lib.rs` نگه می‌دارد و schema آن بدون migration versioning ساخته می‌شود. به همین دلیل، ادغام کامل PR شمارهٔ ۵ یا کپی مستقیم فایل‌ها امن نیست؛ انتقال باید با پشتیبان، مهاجرت و تست سازگاری انجام شود.
