# بازطراحی رابط نبض با React

این شاخهٔ کاری از `main` ساخته شده تا مسیر قدیمی دست‌نخورده بماند.

## تصمیم معماری
- پوسته دسکتاپ: Tauri 2
- رابط: React + TypeScript + Vite
- منطق مالی و پایگاه داده: فرمان‌های Rust و SQLite همین پوسته
- ظاهر: طراحی اختصاصی، راست‌چین، فونت Vazirmatn محلی، رنگ‌های خنثی و سبز برای عملیات اصلی
- موبایل: چیدمان واکنش‌گرا با منوی کناری جمع‌شونده

- [x] مهاجرت ورودی رابط به React + TypeScript
- [x] داشبورد، نمودار روند فروش و ناوبری واکنش‌گرا
- [x] فرم‌های اصلی ثبت طرف‌حساب، کالا، فاکتور، دریافت و پرداخت

## مسیر داده و ایمنی
پوسته فعلی از `app_local_data_dir` با شناسهٔ برنامهٔ `com.herotux.nabz.webprototype` استفاده می‌کند. دیتابیس قدیمی egui در `~/.local/share/nabz/nabz.sqlite3` قرار دارد و schema آن با دیتابیس این پوسته یکسان نیست. این شاخه دیتابیس قدیمی را بازنویسی یا حذف نمی‌کند، اما مهاجرت خودکار داده‌ها هنوز پیاده‌سازی نشده است. تا زمان تکمیل مهاجرت، دیتابیس قدیمی را نگه دار و قبل از استفادهٔ عملی از نسخه جدید، از هر دو مسیر نسخه پشتیبان تهیه کن.

## وضعیت CI
خروجی قابل نصب فقط پس از موفقیت مرحلهٔ ساخت و آپلود artifact در GitHub Actions قابل اعلام است. این شاخه تا زمان مشاهده نتیجهٔ سبز CI و آزمایش بسته روی سیستم مقصد، نسخهٔ پایدار محسوب نمی‌شود.
