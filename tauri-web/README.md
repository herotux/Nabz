# نبض — رابط کاربری Tauri

این نسخهٔ آزمایشی با Tauri 2، Vite و TypeScript ساخته شده و رابط فارسی راست‌چین با چیدمان واکنش‌گرا دارد.

## صفحات طراحی‌شده
- **داشبورد:** کارت‌های شاخص، نمودار فروش، دسترسی سریع و تراکنش‌های اخیر
- **طرف‌حساب‌ها:** فهرست مشتریان/تأمین‌کنندگان، مانده حساب و جست‌وجوی فهرست
- **فاکتورها:** فهرست نمونهٔ فاکتورهای فروش و خرید و فرم‌های اولیهٔ ثبت
- **دریافت و پرداخت:** فهرست تراکنش‌ها و فرم‌های اولیهٔ دریافت/پرداخت
- **کالا و انبار:** فهرست کالاها، کد/بارکد، موجودی و قیمت خرید/فروش
- **گزارش‌ها:** کارت‌های خلاصه و میان‌بر به فهرست‌های مرتبط
- **چاپ و بارکد:** پیش‌نمایش برچسب، فیلدهای بارکد و تنظیمات اولیهٔ چاپ
- **تنظیمات:** اطلاعات فروشگاه، زبان/تقویم/واحد پول، پشتیبان‌گیری و میان‌برها

## وضعیت واقعی قابلیت‌ها
این مرحله تکمیل **پوشش ظاهری صفحات اصلی** است، نه تکمیل نرم‌افزار حسابداری. فهرست‌ها و اعداد هنوز داده‌های نمونه هستند. فرم‌ها اعتبارسنجی و ذخیره‌سازی دائمی کامل ندارند؛ اتصال SQLite و منطق حسابداری Rust هنوز باید پیاده‌سازی شود. چاپگر و بارکد در حال حاضر پیش‌نمایش UI هستند؛ چاپ مستقیم/اسکن USB یا HID هنوز به قابلیت‌های Tauri/Rust متصل نیست. گزینه‌های پشتیبان‌گیری نیز تا اتصال پایگاه داده نمایشی‌اند.

## اجرا
نیازمند Node.js 20+، Rust stable و پیش‌نیازهای Tauri 2:
https://v2.tauri.app/start/prerequisites/

```bash
cd tauri-web
npm install
npm run tauri dev
```

## ساخت
```bash
npm run build
npm run tauri build
```

بیلد لینوکس از طریق GitHub Actions در شاخهٔ `tauri-web-prototype` اجرا می‌شود. پیاده‌سازی در پوشهٔ `tauri-web/` نگه داشته شده تا برنامهٔ قدیمی egui دست‌نخورده بماند.
