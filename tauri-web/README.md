# نبض — نسخهٔ دسکتاپ Tauri

این شاخه نمونهٔ مستقل Tauri 2 + Vite + TypeScript است؛ برنامهٔ قدیمی Rust/egui در این شاخه جایگزین نشده است. رابط کاربری فارسی و راست‌چین است و داده‌های محلی از طریق فرمان‌های Rust و SQLite نگه‌داری می‌شوند.

## بخش‌های رابط
- داشبورد
- طرف‌حساب‌ها
- فاکتورهای فروش و خرید
- دریافت و پرداخت
- کالا و انبار
- گزارش‌ها
- چاپ و بارکد
- تنظیمات

## وضعیت پیاده‌سازی — با احتیاط بخوانید

در کد فعلی schema و فرمان‌های SQLite برای طرف‌حساب‌ها، کالاها، فاکتورها، ردیف فاکتور، دریافت/پرداخت، تنظیمات و گزارش‌ها وجود دارد. تعدادی از فرم‌ها و فهرست‌ها به این لایه متصل شده‌اند و آزمون‌های Rust برای برخی سناریوهای حسابداری نوشته شده‌اند.

این موارد **به معنی آماده‌بودن نرم‌افزار برای حسابداری عملیاتی نیستند**. پیش از استفاده با اطلاعات واقعی، باید CI آخرین commit، سناریوهای حسابداری، حفظ داده پس از اجرای مجدد، همهٔ فرم‌ها، گزارش‌ها و بستهٔ نصب لینوکس بررسی شوند. مواردی مانند ویرایش ایمن اسناد، برگشت از خرید/فروش، پیش‌پرداخت، تطبیق جامع مانده‌ها، آزمون تصویری UI و اجرای واقعی روی Manjaro هنوز معیار پذیرش مستقل دارند.

چاپ فعلاً از مسیر پیش‌نمایش/چاپ مرورگر است؛ چاپ مستقیم سیستم‌عامل و آزمون سخت‌افزاری چاپگر یا بارکدخوان تأیید نشده‌اند. تا پیش از آزمون واقعی، این شاخه را نسخهٔ آزمایشی بدانید و از آن به‌عنوان دفتر حسابداری اصلی فروشگاه استفاده نکنید.

وضعیت دقیق و کارهای باقیمانده در [TODO.md](TODO.md) و [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) ثبت می‌شوند. تیک پیاده‌سازی معادل تأیید آزمون نیست.

## پیش‌نیازها

- Node.js 20 یا جدیدتر
- Rust stable
- پیش‌نیازهای دسکتاپ Tauri 2 و WebKitGTK برای لینوکس

راهنمای رسمی پیش‌نیازها: https://v2.tauri.app/start/prerequisites/

## اجرا در حالت توسعه

```bash
cd tauri-web
npm install
npm run tauri dev
```

## بیلد محلی

```bash
cd tauri-web
npm run build
npm run tauri build
```

پیکربندی فعلی Tauri هدف‌های `deb` و `appimage` را تعریف می‌کند. تا وقتی artifact یک اجرای CI مشخص دانلود و بررسی نشده، موفقیت تولید بسته یا سازگاری آن با Manjaro را نباید فرض کرد.

## دامنهٔ مالیاتی

مدل فاکتور و کالا باید برای تنظیمات مالیاتی اختیاری و تفکیک فاکتور چاپی از صورتحساب الکترونیکی قابل‌گسترش بماند. اتصال فعال به سامانهٔ مؤدیان یا انطباق حقوقی تأیید نشده است؛ پیش از پیاده‌سازی اتصال باید آخرین مستندات رسمی و تکالیف پروندهٔ واقعی بررسی شوند.
