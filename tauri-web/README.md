# نبض — رابط کاربری Tauri

این نسخهٔ آزمایشی با Tauri 2 و Vite/TypeScript ساخته شده و رابط فارسی راست‌چین چندصفحه‌ای دارد.

## صفحات فعلی
- داشبورد با کارت‌های خلاصه، نمودار فروش، دسترسی سریع و آخرین تراکنش‌ها
- طرف‌حساب‌ها: فهرست مشتریان/تأمین‌کنندگان و وضعیت مانده
- فاکتورها: فهرست فاکتورهای فروش و خرید
- دریافت و پرداخت: فهرست تراکنش‌ها و فرم‌های دریافت/پرداخت
- کالا و انبار: فهرست کالا، کد، موجودی و قیمت خرید/فروش
- گزارش‌ها: کارت‌های خلاصه و میان‌بر به گزارش‌های مرتبط

فرم‌ها و فهرست‌ها فعلاً نمونهٔ تعاملی هستند. داده‌ها به SQLite یا منطق حسابداری Rust متصل نشده‌اند و با بستن برنامه پایدار نمی‌مانند؛ اعداد داشبورد نیز نمونه‌اند. این محدودیت عمداً در رابط مشخص شده تا دادهٔ نمایشی با دادهٔ واقعی اشتباه نشود.

## اجرا
نیازمند Node.js 20+، Rust stable و پیش‌نیازهای Tauri 2:
https://v2.tauri.app/start/prerequisites/

```bash
cd tauri-web
npm install
npm run tauri dev
```

## ساخت
```bash
npm run tauri build
```

بیلد لینوکس از طریق GitHub Actions در شاخهٔ `tauri-web-prototype` اجرا می‌شود. این پیاده‌سازی فقط در پوشهٔ `tauri-web/` است تا برنامهٔ قدیمی egui دست‌نخورده بماند.
