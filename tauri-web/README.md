`tauri-web/` is the active React + TypeScript + Vite frontend for the Tauri 2 desktop shell. The UI uses the existing Rust/SQLite Tauri commands; it does not yet provide a standalone web backend. See [REACT_MIGRATION.md](REACT_MIGRATION.md) for migration status and remaining work.

# نبض — نسخهٔ دسکتاپ Tauri

این شاخه رابط React + TypeScript + Vite را در پوسته Tauri 2 اجرا می‌کند؛ برنامهٔ قدیمی Rust/egui در این شاخه جایگزین نشده است. رابط کاربری فارسی و راست‌چین است و داده‌های محلی از طریق فرمان‌های Rust و SQLite نگه‌داری می‌شوند.

## بخش‌های رابط
- داشبورد
- طرف‌حساب‌ها
- فاکتورهای فروش و خرید
- دریافت و پرداخت
- کالا و انبار
- گزارش‌ها
- چاپ و بارکد
- تنظیمات

## وضعیت پیاده‌سازی — با احتیاط بخوانید

در کد فعلی schema و فرمان‌های SQLite برای طرف‌حساب‌ها، کالاها، فاکتورها، ردیف فاکتور، دریافت/پرداخت، تنظیمات و گزارش‌ها وجود دارد. تعدادی از فرم‌ها و فهرست‌ها به این لایه متصل شده‌اند و آزمون‌های Rust برای برخی سناریوهای حسابداری نوشته شده‌اند.

این موارد **به معنی آماده‌بودن نرم‌افزار برای حسابداری عملیاتی نیستند**. پیش از استفاده با اطلاعات واقعی، باید CI آخرین commit، سناریوهای حسابداری، حفظ داده پس از اجرای مجدد، همهٔ فرم‌ها، گزارش‌ها و بستهٔ نصب لینوکس بررسی شوند. مواردی مانند ویرایش ایمن اسناد، برگشت از خرید/فروش، پیش‌پرداخت، تطبیق جامع مانده‌ها، آزمون تصویری UI و اجرای واقعی روی Manjaro هنوز معیار پذیرش مستقل دارند.

چاپ فعلاً از مسیر پیش‌نمایش/چاپ مرورگر است. بارکد Code 128 در رابط تولید می‌شود و اسکنر USB/HID در کادر ورودی به‌صورت صفحه‌کلید قابل استفاده است؛ آزمون سخت‌افزاری چاپگر یا بارکدخوان تأیید نشده است. تا پیش از آزمون واقعی، این شاخه را نسخهٔ آزمایشی بدانید و از آن به‌عنوان دفتر حسابداری اصلی فروشگاه استفاده نکنید.

وضعیت دقیق و کارهای باقیمانده در [TODO.md](TODO.md) و [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) ثبت می‌شوند. تیک پیاده‌سازی معادل تأیید آزمون نیست.

## پیش‌نیازها

- Node.js 20 یا جدیدتر
- Rust stable
- پیش‌نیازهای دسکتاپ Tauri 2 و WebKitGTK برای لینوکس

راهنمای رسمی پیش‌نیازها: https://v2.tauri.app/start/prerequisites/

## اجرا در حالت توسعه

```bash
cd tauri-web
npm install
npm run tauri dev
```

## بیلد محلی

```bash
cd tauri-web
npm run build
npm run tauri build
```

Workflow شاخهٔ بازطراحی یک بستهٔ بومی Arch/Manjaro با پسوند `.pkg.tar.zst` برای x86_64 می‌سازد و آن را با نام artifact `nabz-manjaro-arch-x86_64` نگه می‌دارد. پس از موفقیت Workflow، نصب با `sudo pacman -U ./nabz-tauri-0.1.0-1-x86_64.pkg.tar.zst` انجام می‌شود. تا وقتی artifact سبز CI دانلود و روی Manjaro آزمایش نشده، موفقیت نصب را فرض نکن.

## دامنهٔ مالیاتی

مدل فاکتور و کالا باید برای تنظیمات مالیاتی اختیاری و تفکیک فاکتور چاپی از صورتحساب الکترونیکی قابل‌گسترش بماند. اتصال فعال به سامانهٔ مؤدیان یا انطباق حقوقی تأیید نشده است؛ پیش از پیاده‌سازی اتصال باید آخرین مستندات رسمی و تکالیف پروندهٔ واقعی بررسی شوند.
