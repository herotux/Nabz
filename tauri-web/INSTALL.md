# نصب و ارتقای Nabz روی Arch / Manjaro

> وضعیت: بستهٔ x86_64 در CI ساخته و اعتبارسنجی می‌شود. انتشار هنوز Draft است؛ نصب‌کننده فقط پس از انتشار یک GitHub Release عمومی و دارای checksum کار می‌کند.

## نصب یک‌مرحله‌ای

پس از انتشار Release عمومی:

```bash
curl -fsSL https://raw.githubusercontent.com/herotux/Nabz/ui/react-tauri-redesign/tauri-web/install.sh | bash
```

اسکریپت:
1. فقط معماری x86_64 را می‌پذیرد.
2. آخرین Release منتشرشده را از GitHub می‌گیرد؛ Releaseهای Draft قابل نصب نیستند.
3. بستهٔ Arch و فایل SHA-256 را دریافت و checksum را پیش از نصب بررسی می‌کند.
4. وابستگی‌های runtime را از مخازن رسمی Arch/Manjaro نصب می‌کند.
5. اگر دیتابیس موجود باشد، با SQLite Backup API یک نسخهٔ پشتیبان پیش از ارتقا در پوشهٔ backups می‌سازد.
6. بسته را با pacman نصب/ارتقا می‌کند؛ پوشهٔ دادهٔ کاربر را پاک یا جابه‌جا نمی‌کند.

برای بازبینی پیش از اجرا می‌توان اسکریپت را دانلود و سپس با `bash install.sh` اجرا کرد.

## نصب دستی بستهٔ CI

از اجرای موفق workflow، artifact با نام `nabz-manjaro-arch-x86_64` را دریافت کنید. پس از استخراج:

```bash
sha256sum --check nabz-tauri-0.1.0-1-x86_64.pkg.tar.zst.sha256
sudo pacman -S --needed webkit2gtk-4.1 gtk3 openssl
sudo pacman -U --needed ./nabz-tauri-0.1.0-1-x86_64.pkg.tar.zst
```

## مسیر داده و حفظ اطلاعات

دیتابیس اصلی در مسیر زیر است:

```
~/.local/share/com.herotux.nabz/nabz.sqlite3
```

در صورت تنظیم `XDG_DATA_HOME`، همان مسیر جایگزین `~/.local/share` می‌شود. فایل‌های backup در زیرپوشهٔ `backups` قرار می‌گیرند. بستهٔ برنامه در `/usr` نصب می‌شود و دادهٔ کاربر خارج از آن است.

**حذف برنامه:** حذف بسته با pacman فایل‌های برنامه را حذف می‌کند؛ این بسته اسکریپت حذف داده ندارد و پوشهٔ دیتابیس کاربر را پاک نمی‌کند. با این حال قبل از هر حذف/ارتقای مهم، backup مستقل نگه دارید.

## محدودیت‌های پذیرش

- بسته و اسکریپت برای x86_64 هستند؛ ARM64/Raspberry Pi در این خروجی پشتیبانی نمی‌شود.
- نصب تمیز، ارتقا و حذف روی دستگاه واقعی Manjaro هنوز باید آزمایش شود.
- اجرای برنامه از منوی دسکتاپ در CI بررسی ساختار بسته است، نه آزمون تعاملی روی دسکتاپ واقعی.
- checksum خرابی تصادفی/دریافت ناقص را کشف می‌کند؛ امضای رمزنگاری‌شدهٔ ناشر یا امضای بسته هنوز ارائه نشده است.
- installer آخرین Release عمومی را نصب می‌کند؛ نسخه‌های Draft و artifactهای موقت Actions را نصب نمی‌کند.
